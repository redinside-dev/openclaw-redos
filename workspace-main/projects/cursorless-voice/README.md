# Cursorless Voice

Open-source voice coding platform that enables developers to write, edit, and navigate code using natural language voice commands.

## Getting Started

1. Install dependencies: `npm install`
2. Start development: `npm run dev`
3. Build for production: `npm run build`

## Features

- Voice command system for coding
- Natural language processing
- IDE integration (VS Code)
- Real-time code editing

## Architecture

- **Frontend**: Electron + React + TypeScript
- **Backend**: Node.js + Python NLP
- **Voice**: Web Speech API + Whisper
