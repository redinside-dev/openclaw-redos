## 🔧 If Something Goes Wrong

### Bot not responding?
```bash
# Check bridge
ps aux | grep telegram-bridge

# Restart if needed
cd ~/.openclaw && node telegram/telegram-bridge.js &
```

### Gateway not responding?
```bash
# Check gateway
curl http://localhost:19000/health

# Restart if needed
cd ~/.openclaw && npm start &
```

### View logs
```bash
tail -f /tmp/openclaw-gateway.log
tail -f /tmp/telegram-bridge.log
```
