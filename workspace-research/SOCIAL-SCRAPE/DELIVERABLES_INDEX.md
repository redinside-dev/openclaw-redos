## 🔧 Installation Methods

### Method 1: Standard npm
```bash
cd SOCIAL-SCRAPE
npm install
npx playwright install chromium
cp .env.example .env
npm test
```

### Method 2: Quick Setup Script
```bash
cd SOCIAL-SCRAPE
./setup-browser.sh
npm test
```

### Method 3: Docker
```bash
cd SOCIAL-SCRAPE
docker build -t social-scrape .
docker run -d --name scraper social-scrape
```

### Method 4: Docker Compose
```bash
cd SOCIAL-SCRAPE
docker-compose up -d
```
