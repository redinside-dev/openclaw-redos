## Key Findings

### 1. Self-Healing CI/CD (most actionable)
- AI agents now generate self-correcting PRs when tests fail (autonomous adaptation to schema changes, dynamic UI elements)
- Self-healing test frameworks detect changes in app automatically and update tests on the fly
- Best practice: Review AI-based locator updates before permanent approval; ensure self-healing runs seamlessly in pipelines

### 2. AI Code Review Tools 2026
- **Graphite**: Enforces small PR changes
- **GitHub Copilot**: Sacrifices depth for speed
- **Greptile**: Indexes entire codebase upfront
- Claude Code, IBM Bob for terminal-based review

### 3. SWE-bench
- **SWE-Bench Pro (public)**: Top models ~23% (much harder)
- **SWE-Bench Verified**: Top models 70%+
- **Claude Opus 4.5**: 80.9% on Verified (leader)
- Gemini 3.1 Pro leads Terminal-Bench 2.0 at 78.4%

## Relevance to Coding Factory POC
Self-healing test automation is directly applicable - pipeline can auto-fix broken tests instead of failing.
