# ENG R&D Research — 2026-02-24

## Topics
- AI coding agent benchmarks (SWE-bench)
- Self-healing CI/CD pipelines
- Code review automation tools

## Findings (relevant to coding factory POC)

1) SWE-bench remains the most cited real-world issue benchmark for coding agents. The official site highlights multiple tracks (Verified, Lite, Multilingual) and makes clear that Verified is the most rigorous split for Python issue resolution. This remains the primary yardstick for autonomous coding agent progress and is useful for POC evaluation criteria.
- Source: https://www.swebench.com
- Source: https://www.swebench.com/viewer.html

2) Self-healing CI/CD pipeline pattern: event-driven failure detection + automated recovery playbooks (retry with adjusted timeouts, stage-level retries, rollback) + capped feedback loops to avoid infinite retries. This can reduce MTTR and is aligned with an autonomous coding factory POC that needs reliability in CI.
- Source: https://dev.to/aws-builders/implementing-a-self-healing-serverless-cicd-pipeline-with-aws-developer-tools-611
- Source: https://optimumpartners.com/insight/how-to-architect-self-healing-ci/cd-for-agentic-ai/

3) Code review automation: GitHub Copilot Code Review can be enabled via rulesets to auto-request reviews; Claude provides GitHub Actions integration. These are low-friction ways to add LLM review gates in PR flows for the POC.
- Source: https://docs.github.com/en/copilot/how-tos/use-copilot-agents/request-a-code-review/configure-automatic-review
- Source: https://code.claude.com/docs/en/github-actions
