# Daily Improvement Log

This directory holds one file per day: `YYYY-MM-DD.md`.

**Purpose:** "What got better today" and "Tomorrow's focus" — filled by RED Self-Improvement Reflection cron so we have a measurable daily improvement record.

**Format (each file):**
- ## Today's improvements
  - Bullet list: what we learned, what we fixed, what got better today
- ## Tomorrow's focus
  - Bullet list: what the team should focus on tomorrow

RED must write today's file on every self-improvement reflection run (see cron job "RED Self-Improvement Reflection"). Create this directory if missing.
