## How to Use This Index

**When you encounter an issue:**
1. Search this file for keywords
2. Click the solution link
3. Follow the documented steps
4. If it works, great!
5. If not, document the variation

**When you solve a new issue:**
1. Create solution document in `/shared/solutions/[issue-name].md`
2. Add entry to this index under appropriate category
3. Include: date, agent who solved it, brief description, link

**Template for new entry:**
```
- **[Issue Name]** - [Brief description] | Solved by [AGENT] on [DATE] | [Link to solution](/workspace/memory/shared/solutions/issue-name.md)
```
